סרטון אנימציה של 30 שניות עם קריאה לפעולה, לפייסבוק ולאינסטגרם.

## קבצים

| קובץ | פורמט | לאן |
|---|---|---|
| `yarok-hevrati-promo-1080x1080.mp4` | 1:1, 1080×1080, 30fps | פיד פייסבוק, פיד אינסטגרם, מודעות |
| `yarok-hevrati-promo-1080x1920.mp4` | 9:16, 1080×1920, 30fps | Reels, Stories (אינסטגרם + פייסבוק) |

| `render.js` | סקריפט רינדור | מייצר את ה-MP4 מהדף |

## עריכה ורינדור מחדש

הטקסטים, הצבעים והתזמונים נמצאים ב-`promo.html` (משתני CSS ב-`:root`, מערך `SCENES` ב-JS).

```bash
npm install playwright        # פעם אחת; נדרש גם ffmpeg ב-PATH (או FFMPEG=/path/to/ffmpeg)
node render.js square         # 1080x1080
node render.js story          # 1080x1920
node render.js all
```
