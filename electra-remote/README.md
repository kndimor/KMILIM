# שלט אלקטרה (Electra AC Remote)

שלט רחוק למזגן אלקטרה בצורת אתר שאפשר להתקין על הטלפון כאפליקציה (PWA).

## מה יש בפנים

| קובץ | תפקיד |
|---|---|
| `index.html` | השלט עצמו: מסך LCD, כפתורים, הגדרות, יומן פקודות. קובץ אחד, בלי תלויות. |
| `manifest.webmanifest`, `sw.js`, `icon.svg` | הופכים את הדף לאפליקציה מותקנת שעובדת גם בלי אינטרנט. |
| `server.js` | שרת קטן (Node, בלי חבילות) שמגיש את הדף ומתווך מול ענן Electra Smart. |

## כפתורים

ON/OFF, טמפרטורה 16–30, MODE (קירור / חימום / ייבוש / אוורור / אוטומטי), FAN (אוטומטי / נמוך / בינוני / גבוה), SWING, TURBO, SLEEP, I FEEL, TIMER (חצי שעה עד 12 שעות, סופר באמת ומכבה או מדליק), מצב שבת, SYNC (רענון מהמזגן) ו‑SEND (שליחה חוזרת).
מקלדת: חיצים למעלה/למטה לטמפרטורה, רווח להדלקה, `M` למצב, `F` למאוורר.

## שלושה מצבי חיבור

1. **הדגמה מקומית** (ברירת מחדל). הכל עובד על המסך ונשמר במכשיר, אבל שום פקודה לא יוצאת החוצה.
2. **Electra Smart**. למזגן עם מודול Wi‑Fi של אלקטרה. מתחברים עם מספר הטלפון שרשום באפליקציית Electra Smart, מקבלים קוד ב‑SMS, בוחרים מזגן, ומאותו רגע השלט שולט במזגן ומציג את הטמפרטורה בחדר.
3. **Webhook / IR**. כל לחיצה שולחת `POST` עם JSON של מצב השלט לכתובת שתגדיר. מתאים ל‑Home Assistant (webhook trigger), ESPHome / Tasmota עם משדר IR, או Broadlink דרך שרת קטן.

## הרצה

```bash
cd electra-remote
node server.js
# פתח http://localhost:8787
```

צריך Node 18 ומעלה. כדי להשתמש מהטלפון, פתח את כתובת המחשב ברשת הביתית, למשל `http://192.168.1.20:8787`, ואז "הוסף למסך הבית".

בלי Node אפשר גם פשוט לפתוח את `index.html` בדפדפן או להעלות את התיקייה ל‑GitHub Pages. במקרה כזה מצב "Electra Smart" צריך שרת שרץ איפשהו, והכתובת שלו נכנסת בשדה "כתובת השרת" בהגדרות.

## מבנה ה‑JSON שנשלח ב‑Webhook

```json
{
  "source": "electra-remote",
  "sentAt": "2026-09-29T18:00:00.000Z",
  "power": true,
  "mode": "cool",
  "temp": 24,
  "fan": "auto",
  "swing": false,
  "turbo": false,
  "sleep": false,
  "ifeel": false,
  "shabbat": false,
  "timerHours": 0,
  "electra": {
    "OPER": { "AC_MODE": "COOL", "SPT": "24", "FANSPD": "AUTO", "VSWING": "OFF", "HSWING": "OFF", "TURBO_MODE": "OFF", "SLEEP": "OFF", "IFEEL": "OFF", "SHABAT": "OFF", "TIMER": "OFF" }
  }
}
```

`electra.OPER` הוא בדיוק המבנה שענן Electra Smart מקבל, כך שאפשר להעביר אותו הלאה כמו שהוא.

## הערות

- הפרוטוקול מול ענן אלקטרה מבוסס על מה שאפליקציית Electra Smart ואינטגרציית Home Assistant משתמשות בו. הוא לא מתועד רשמית ועלול להשתנות.
- השרת לא שומר סיסמאות או טוקנים. הטוקן נשמר בדפדפן שלך בלבד ונשלח לשרת בכל בקשה.
- דף ב‑HTTPS לא יכול לדבר עם שרת ב‑HTTP ברשת הביתית (mixed content). אם מארחים את הדף ב‑HTTPS, גם השרת צריך HTTPS, או שפותחים את הדף ישירות מהשרת.
